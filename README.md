# TaskbarApp

Нативная панель задач в стиле Windows для macOS. Показывает открытые окна как кнопки-плитки внизу экрана и умеет переключаться между ними, сворачивать/разворачивать, закрывать, переносить на другой монитор и прятать системный Dock.

Написано на Swift/AppKit.

## Поддерживаемые ОС

| | Требование |
| --- | --- |
| **macOS** | **13 Ventura** и новее (Sonoma, Sequoia, Tahoe) |
| **Архитектура** | Apple Silicon (M1/M2/M3/M4) и Intel — сборка universal |
| **Права** | Разрешение «Универсальный доступ» (Accessibility) |
| **Языки** | Русский, English — авто по языку системы + ручной выбор (меню приложения → «Язык») |

> Windows и Linux не поддерживаются — приложение использует macOS AppKit и Accessibility API.

## Быстрая установка

1. Скачайте последний `TaskbarApp-*.zip` со страницы [Releases](../../releases).
2. Распакуйте и перетащите `TaskbarApp.app` в **/Applications**.
3. Первый запуск — **ПКМ → «Открыть»** (приложение не нотаризовано, Gatekeeper покажет предупреждение «неопознанный разработчик»).
4. В появившемся запросе разрешите **Универсальный доступ** (Accessibility), либо вручную:

   **System Settings → Privacy & Security → Accessibility** → включите `TaskbarApp`.

Готово — панель появится внизу экрана.

## Возможности

- **Панель на каждом экране** — как Windows Taskbar, работает с несколькими мониторами (перестраивается при подключении/отключении дисплея).
- **Плитки приложений** — иконка + название; активное приложение подсвечивается индикатором.
- **Клик по плитке** — переключение на приложение (активирует его окно).
- **Правый клик по плитке** — контекстное меню:
  - `●` Вывести на передний план
  - `●` Растянуть на экран (окно занимает весь экран минус высота панели)
  - `●` Переместить на экран N (если мониторов больше одного)
  - `●` Закрыть окно
  - `●` Завершить приложение
  - список окон приложения (если окон несколько) — переключение на конкретное окно
- **Бейдж количества окон** — красный кружок с числом окон у приложения.
- **Кнопка «Пуск»** слева — меню: Finder, Системные настройки, список программ, выход.
- **Автоматическое сжатие** плиток при переполнении (до режима «только иконка»).
- **Скрытие системного Dock** — пункт меню приложения, со сторожевым процессом для защиты от случайного исчезновения Dock.

## Использование

| Действие | Что делает |
| --- | --- |
| ЛКМ по плитке | Переключиться на приложение |
| ПКМ по плитке | Контекстное меню (см. выше) |
| Кнопка «Пуск» (слева) | Finder / настройки / программы / выход |
| Меню TaskbarApp → «Скрыть системный Dock» | Спрятать Dock |
| Меню TaskbarApp → «Вернуть системный Dock» | Вернуть Dock |

## Известные ограничения

- **Настоящий Fullscreen** (отдельный Space) панель перекрыть не может — macOS не отдаёт сторонним окнам уровень выше. Используйте «Растянуть на экран» (maximize-поведение) вместо Fullscreen.
- Приложение не нотаризовано Apple — первый запуск через **ПКМ → «Открыть»**.
- Приложение без открытых окон в панели не показывается (как в Windows/Dock).
- Бейджи и «мигание» иконок чужих приложений не поддержаны — публичного API нет (подробнее в `UBAR_RESEARCH.md`).

## Приватность и безопасность

- **Без сети и телеметрии** — приложение не делает сетевых запросов, ничего не собирает и никуда не отправляет. Весь код открыт, его можно проверить.
- **Accessibility** используется только для показа и переключения окон — и ни для чего другого.

## Удаление

1. `TaskbarApp` → «Выйти из TaskbarApp» (или «Вернуть системный Dock», если Dock был скрыт).
2. Удалите `TaskbarApp.app` из /Applications.

## Для разработчиков

### Сборка из исходников

```bash
git clone https://github.com/onitreyn/MacTaskBar.git
cd MacTaskBar/TaskbarApp

# 1. Создать локальный self-signed сертификат подписи (нужно ОДИН раз)
./scripts/create_dev_cert.sh

# 2. Собрать и подписать приложение
./build_app.sh

# 3. Запустить
open build/TaskbarApp.app
```

Требования к окружению: macOS 13+, Xcode (или Command Line Tools) со Swift 5.9+.

### Сборка релиза (zip для распространения)

```bash
./scripts/make_release.sh
# результат: dist/TaskbarApp-<version>.zip (universal: arm64 + x86_64)
```

### Зачем нужен self-signed сертификат

Приложение читает окна через Accessibility API. macOS привязывает разрешение Accessibility к подписи приложения; ad-hoc подпись (по умолчанию у debug-сборок) меняется при каждой перекомпиляции, и система считает пересобранное приложение новым — разрешение сбрасывается. Собственный сертификат `TaskbarApp Local Dev` даёт стабильную идентичность, к которой разрешение привязывается навсегда.

### Сторож Dock (опционально)

Если вы скрыли системный Dock через меню приложения, сторож гарантирует, что Dock вернётся при выходе из TaskbarApp или его падении:

```bash
./scripts/install_watchdog.sh        # установить
./scripts/uninstall_watchdog.sh      # удалить
```
